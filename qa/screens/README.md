# Reference photographs

These are test evidence, not documentation: the pictures
[`qa/story_look.py`](../story_look.py) compares a fresh run against, to
notice a screen that changed shape while nobody was looking. Several are
staged at awkward moments on purpose — a popup at its limit, a card
carrying everything a card can carry, a title too long for its row.

The documentation's own pictures are in
[`docs/screenshots/`](../../docs/screenshots/README.md). How these are
taken, compared and approved is in
[the qa README](../README.md#photographs-did-a-screen-change-shape-while-nobody-was-looking).
